01 — PRIORITIZE

重点有理由。
主次有层次。

将内容分为「重点」「次要」「了解即可」，说明分级依据，以及需要达到的掌握标准。先用 30 秒看清核心，再按需深入。

知道要学什么，也知道学到什么程度。

02 — CLARIFY

纠正一个错误。
理清一层理解。

把原记录、问题、修正与依据放在一起。可以确认的错误明确修正；冲突数字和无法确认的事实，单列待确认。

看见结论，也看见它为什么成立。

学习笔记和会议记录，可以一起整理吗？

可以。Skill 会识别学习、会议与混合材料，分别按理解与复习、决策与跟进组织，再用摘要连接两部分。

会输出哪些格式？

默认同时生成 HTML 与 Word（.docx）两个文件，两份知识、表格与答案一致。HTML 便于离线阅读和折叠自测，Word 便于编辑与打印。

怎样处理信息不完整或内容有冲突？

保留原记录与来源标记。可以确认的错误说明修正依据；无法确认的事实、冲突数据、缺失负责人或截止日，都明确标记待确认。

使用它需要什么环境？

需要支持 Codex Skills 的运行环境。双格式导出脚本需要 Python 3 与 python-docx；HTML 和 SVG 脚本仅用标准库。它依据你提供的记录工作，录音或转写材料需先通过可用工具准备。
